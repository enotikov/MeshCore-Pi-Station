# MeshCore Pi Station 0.7.0

## Русский

Релиз посвящён надёжности очереди, восстановлению данных и защите первого входа.

- Одноразовый код первого входа, обязательный постоянный пароль при завершении мастера и ограничение неверных попыток входа.
- Немедленное применение нового пароля, закрытие WebSocket-соединений и защита от межсайтовых запросов.
- Отмена сообщений в очереди, ручной повтор и выбор срока ожидания от 15 минут до 7 дней.
- Статус «доставка не подтверждена» вместо автоматической повторной передачи после неопределённого результата.
- Проверка и подготовка восстановления на отдельной базе, снимок до изменения и сохранение истории статусов.
- Сообщения из восстановленной очереди не отправляются без ручного решения.
- Обновлённые русское и английское руководства.

**Изменение входа:** при отсутствии постоянного пароля прочитайте код командой `sudo cat /var/lib/meshcore-pi-station/setup-token`. Имя пользователя по умолчанию — `meshcore`. Используйте доверенную локальную сеть или заранее настройте HTTPS. Пароль меняется сразу; изменения транспорта и HTTPS требуют перезапуска службы.

Копии содержат данные SQLite и политику хранения, но не `station.json`, пароль входа, BLE PIN, TLS-файлы, карты, статистику или identity радио. Снимки перед восстановлением хранятся в каталоге `recovery` незашифрованными, с ограниченными правами Linux, и требуют контроля свободного места.

Установка:

```bash
sha256sum -c meshcore-pi-station_0.7.0_all.deb.sha256
sudo apt install ./meshcore-pi-station_0.7.0_all.deb
```

Проверено 27 автоматическими тестами и в браузере с симулятором. Установка на Raspberry Pi и испытания с физическим Heltec не выполнялись. Обновление приложения из интерфейса, полные системные архивы и управление сессиями в этот релиз не входят.

## English

- Protected initial access, permanent-password setup, login throttling and immediate credential changes.
- Queue cancellation, manual retry, selectable expiry and explicit unconfirmed delivery without implicit RF retries.
- Validated staged backup merging, pre-restore snapshots and preserved message timelines.
- Imported queued messages require manual retry. Pending messages are protected from history pruning.
- Updated RU/EN documentation with migration and recovery instructions.

Without a configured password, read `/var/lib/meshcore-pi-station/setup-token` locally and sign in as `meshcore` (unless a different username is configured). Use a trusted network or configure TLS first. Backups exclude connection/login/TLS configuration, maps, statistics and radio identity. Recovery snapshots contain unencrypted secrets and are access-restricted on Linux.

27 automated tests passed; browser checks used the simulator. No physical Raspberry Pi installation or Heltec testing was performed. In-app self-updates, full system archives and session management are deferred.
