# MeshCore Pi Station 1.0.0

Release date: 2026-09-05

## Русский

Версия 1.0.0 закрепляет стабильную основу локальной станции MeshCore.

- Центр активных предупреждений с уровнями важности, подтверждением и сбросом подтверждений.
- Графики RSSI, SNR и числа пакетов за 24 часа, 7 или 30 дней с фильтром по узлу.
- Ограниченная агрегация внутри SQLite без загрузки полной истории в память Raspberry Pi.
- История маршрутов: направление, узел, время, число переходов и доступные path/route metadata.
- Проверка актуального GitHub Release с показом только HTTPS-ссылок на `.deb` и `.sha256`.
- Проверка обновлений никогда не запускает `apt` и не устанавливает код автоматически.
- Сохранены аналитика доставки, диагностика Raspberry Pi, поиск, зашифрованные копии, прошивка Heltec и лимит сообщения 133 символа.

Установка:

```bash
sha256sum -c meshcore-pi-station_1.0.0_all.deb.sha256
sudo apt install ./meshcore-pi-station_1.0.0_all.deb
sudo systemctl status meshcore-pi-station
```

Пройдено 36 автоматических тестов. По решению владельца проекта физические испытания на Raspberry Pi и Heltec при подготовке 1.0.0 пропущены; функции оборудования не считаются подтверждёнными полевым тестом.

## English

Version 1.0.0 establishes the stable baseline for the local MeshCore station.

- Active-warning center with severity, acknowledgement and acknowledgement reset.
- RSSI, SNR and packet-volume charts for 24 hours, 7 days or 30 days, filterable by node.
- Bounded SQLite-side aggregation without loading the complete history into Raspberry Pi memory.
- Route history with direction, node, timestamp, hop count and available path/route metadata.
- Latest GitHub Release check exposing only HTTPS `.deb` and `.sha256` links.
- Update checks never execute `apt` or automatically install code.
- Delivery analytics, Raspberry Pi diagnostics, search, encrypted backups, Heltec flashing and the 133-character message limit remain available.

```bash
sha256sum -c meshcore-pi-station_1.0.0_all.deb.sha256
sudo apt install ./meshcore-pi-station_1.0.0_all.deb
sudo systemctl status meshcore-pi-station
```

The release passed 36 automated tests. At the project owner's direction, physical Raspberry Pi and Heltec testing was skipped for 1.0.0; hardware functions are not claimed as field-verified.
