# MeshCore Pi Station 1.0.1

Prepared: 2026-09-22. This patch does not replace the immutable 1.0.0 release.

## English

- Backup export, encryption, restore and database health work run outside the async request loop.
- Exports use a consistent, read-only SQLite snapshot, close it explicitly and batch message timelines.
- CSV exports neutralize spreadsheet formulas; live browser packet history is limited to 500 records.
- Automatic-backup names avoid collisions during rapid creation.
- Runtime dependencies come from `uv.lock`. The installer builds a replacement venv at its permanent path, checks imports and dependencies, then switches the active symlink. Failed activation restores the previous environment. Previous environments remain available for manual recovery; package metadata and database changes are not automatically rolled back.
- Source installation builds and installs the same Debian package. CI checks the current package, constraints, checksum and shell syntax, with Linux install/upgrade/failure tests.
- The service explicitly sets state-directory mode 0750 and umask 0077, preserving private data permissions across restarts.
- Browser asset/cache revision increases to 20.

Install the package with `sudo apt install ./meshcore-pi-station_1.0.1_all.deb`.
Installation requires network access to PyPI. Fresh installations start in mock mode,
with firmware flashing disabled. Physical Raspberry Pi installation, Heltec V4 USB flashing and serial operation were verified as described below; BLE remains unverified.

## Русский

- Экспорт, шифрование и восстановление резервных копий, а также проверка базы вынесены из цикла обработки асинхронных запросов.
- Экспорт использует согласованный SQLite-снимок только для чтения, явно закрывает соединение и загружает историю статусов одним запросом.
- CSV нейтрализует формулы электронных таблиц; история пакетов в браузере ограничена 500 записями.
- Имена автоматических резервных копий защищены от коллизий при быстром создании.
- Версии зависимостей берутся из `uv.lock`. Установщик создаёт новое окружение сразу по постоянному пути, проверяет импорт и зависимости, затем переключает символьную ссылку. При ошибке запуска возвращается прежнее окружение. Старые окружения сохраняются для ручного восстановления; метаданные пакета и изменения базы автоматически не откатываются.
- Установка из исходников собирает и устанавливает тот же Debian-пакет. CI проверяет актуальный пакет, зависимости, контрольную сумму и синтаксис оболочки; добавлены Linux-тесты установки, обновления и отказов.
- Служба явно задаёт права каталога данных 0750 и umask 0077, сохраняя закрытый доступ после перезапуска.
- Версия браузерных ресурсов и кеша повышена до 20.

Установка: `sudo apt install ./meshcore-pi-station_1.0.1_all.deb`.
Нужен доступ к PyPI. Новая установка запускается в режиме симулятора,
прошивка отключена. Установка на Raspberry Pi, прошивка Heltec V4 по USB и работа serial проверены ниже; BLE пока не проверен.

## Map correction / Исправление карты

The first browser check exposed blocked OpenStreetMap tiles. The application's
`no-referrer` response policy suppressed the Referer required by OSM. It now uses
`strict-origin-when-cross-origin`: external tiles receive only the station origin,
without page paths, query parameters or credentials. Browser caching and the tile
provider are unchanged. See the [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/).
The new regression and all 14 API tests passed; the suite now contains 59 tests.
A single correctly identified diagnostic tile request returned HTTP 200 image/png.

При первой проверке в браузере обнаружены заблокированные тайлы OpenStreetMap.
Политика `no-referrer` заменена на `strict-origin-when-cross-origin`: сервер карты
получает только адрес станции без пути, параметров страницы и пароля. Провайдер
карты и обычное кеширование браузера сохранены. Все 14 тестов API прошли; общее
число тестов — 59. Одиночный диагностический запрос тайла вернул HTTP 200 image/png.

The corrected package is installed on the Pi. Authenticated HTML confirms the new Referrer-Policy; service health, mock mode and disabled flashing are verified. Reload the map page in the browser.

Исправленный пакет установлен на Pi; новый заголовок проверен на странице после авторизации. Служба работает, симулятор и запрет прошивки сохранены. Обновите страницу карты в браузере.

## Physical Heltec V4 verification / Проверка Heltec V4

A physical Heltec WiFi LoRa 32 V4 (ESP32-S3, 16 MB flash, 2 MB PSRAM) was backed
up and flashed with the official full USB Companion 1.17.1 merged image. Download
SHA-256 and the written image were verified. The live Companion protocol reports
`Heltec V4 OLED`, `v1.17.1-d929643`, and the station is connected over USB serial.
The original 16 MB flash backup remains securely on the Pi. ESP32-S3 native USB
required `plugdev`; Raspberry Pi power diagnostics required `video`. Package installation now grants both groups when available.
RF messaging and regional radio configuration remain to be tested separately.

Физический Heltec WiFi LoRa 32 V4 (ESP32-S3, flash 16 МБ, PSRAM 2 МБ) сохранён в
полный резервный образ и прошит официальным полным USB Companion 1.17.1. Хеш
загрузки и записанных данных проверен. Companion отвечает как `Heltec V4 OLED`
версии `v1.17.1-d929643`, станция подключена по USB serial. Исходный снимок flash
хранится на Pi с закрытыми правами. Для native USB ESP32-S3 потребовалась группа
`plugdev`, а диагностика питания Raspberry Pi — группу `video`; установщик добавляет обе группы при наличии. Радиообмен и региональные
настройки частоты ещё требуют отдельной проверки.
