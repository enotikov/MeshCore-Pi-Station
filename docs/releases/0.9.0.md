# MeshCore Pi Station 0.9.0

Release date: 2026-09-05

## Русский

Версия 0.9.0 развивает станцию в сторону эксплуатации и анализа качества mesh-сети.

- Аналитика связи по каждому известному узлу за 24 часа, 7 или 30 дней: средние SNR/RSSI, RX/TX, подтверждение прямых сообщений, задержка, hops и последняя активность.
- Оптимизированная SQLite-агрегация, не загружающая всю историю пакетов в память Raspberry Pi.
- Единый экран состояния радио, очереди сообщений, базы и автоматических копий.
- Диагностика памяти, пониженного напряжения, ограничения частоты, температуры и throttling Raspberry Pi.
- Ручное переподключение Heltec, недоступное во время прошивки.
- Глобальный поиск сообщений по тексту, узлу или каналу, статусу и диапазону дат.
- Зашифрованные автоматические копии с расписанием, ротацией, скачиванием и восстановлением.
- Диагностический отчёт без сообщений, координат, контактов, паролей и ключей.
- Лимит исходящего сообщения 133 символа в браузере и API.

Обновление сохраняет существующую SQLite-базу и конфигурацию. Перед установкой рекомендуется создать парольный `.mcps` backup и отдельно сохранить identity. Автоматические `.mcpsa` используют ключ конкретной станции; сохраните `automatic-backup.key`, если планируете аварийное восстановление этих файлов.

Установка:

```bash
sha256sum -c meshcore-pi-station_0.9.0_all.deb.sha256
sudo apt install ./meshcore-pi-station_0.9.0_all.deb
sudo systemctl status meshcore-pi-station
```

Проверено 33 автоматическими тестами и в браузере с симулятором. Установка 0.9.0 на физическую Raspberry Pi и испытания с реальным Heltec в рамках подготовки релиза не выполнялись.

## English

Version 0.9.0 focuses on station operations and mesh link analysis.

- Per-node analytics for 24 hours, 7 days or 30 days: average SNR/RSSI, RX/TX, direct-message confirmation, latency, hops and last activity.
- SQLite-side aggregation designed not to load the complete packet history into Raspberry Pi memory.
- Unified radio, message-queue, database and automatic-backup health view.
- Raspberry Pi memory, undervoltage, frequency-cap, temperature and throttling diagnostics.
- Manual Heltec reconnection, blocked while firmware flashing is active.
- Global message search by content, node/channel, status and date range.
- Encrypted scheduled backups with rotation, download and restore.
- Privacy-filtered support reports without messages, coordinates, contacts, passwords or keys.
- A 133-character outbound-message limit in the browser and API.

The upgrade preserves the existing SQLite database and configuration. Create a password-protected `.mcps` backup and preserve the radio identity before installation. Automatic `.mcpsa` files use a station-specific key; retain `automatic-backup.key` for disaster recovery.

```bash
sha256sum -c meshcore-pi-station_0.9.0_all.deb.sha256
sudo apt install ./meshcore-pi-station_0.9.0_all.deb
sudo systemctl status meshcore-pi-station
```

The release passed 33 automated tests and browser checks with the simulator. It was not installed on a physical Raspberry Pi or tested with a physical Heltec during release preparation.
